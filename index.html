Project

What is the Film Production Dashboard?

The Film Production Dashboard is a Streamlit web app that allows users to explore and analyze movie production data through interactive tables, filters, charts, and automatic calculations.

```

🎞️ Project Description

The app includes pre-loaded data from five famous movies and allows users to add new movie data. Each movie includes title, director, year, genre, budget, and revenue.

Based on budget and revenue, the dashboard automatically calculates profit and ROI. It then visualizes the results through charts and key metric cards.

🎯 Project Goal

The goal of this project is to create a simple but meaningful data hub for film production analysis.

It demonstrates how a film-related topic can be turned into an interactive web dashboard using Python, Streamlit, Pandas, Plotly, GitHub, and AI-assisted coding.

Features

Main features of the dashboard

The dashboard is designed to be interactive and easy to understand, even for users who are not familiar with coding.

```

➕ Add Movies

Users can add new movie data through the sidebar, including title, director, year, genre, budget, and revenue.

💰 ROI Calculation

The app automatically calculates profit and ROI using the movie budget and revenue.

📊 Budget vs Revenue

A bar chart compares each movie’s budget and revenue, making financial performance easier to see.

🥧 Genre Distribution

A pie chart shows how the movies are distributed by genre.

🎞️ Decade Filter

Users can filter movies by decade to focus on specific time periods.

🏆 Top ROI Ranking

The dashboard ranks movies by ROI and shows which films performed best financially.

```
Data

Movie data used in the dashboard

The dashboard uses movie production data with six main fields. These fields are used to calculate profit, ROI, and visual comparisons.

```
Data Field Description
Title The name of the movie
Director The director of the movie
Year The release year of the movie
Genre The movie genre, such as Action, Sci-Fi, Thriller, or Romance
Budget The estimated production cost of the movie
Revenue The box office revenue of the movie
