# 🎬 PRD: Film Production Data Hub Dashboard

## 1. Project Title

**Film Production Data Hub Dashboard**

## 2. Project Overview

This project is a Streamlit-based web dashboard for analyzing film production data.
The dashboard allows users to explore movies by title, director, year, genre, budget, revenue, profit, and ROI.

The goal of this project is to create an interactive data hub that connects my interest in film production with data visualization. Users can compare movie budgets and revenues, understand genre distribution, filter movies by decade, and evaluate financial performance through ROI.

## 3. 5W1H Framework

### Why

I am making this project because I am interested in film production and want to understand how movies perform financially.
As a film student, I usually think about storytelling, directing, and production design, but this project helps me look at films from a data perspective.
By analyzing budget, revenue, profit, and ROI, I can better understand the relationship between creative production and commercial results.

### Who

This dashboard is for:

* Film students
* Movie producers
* Film industry researchers
* People interested in box office performance
* Anyone who wants to compare movie budgets and revenues visually

### What

The dashboard will include the following key features:

1. **Movie data table**
   Users can view movie information such as title, director, year, genre, budget, revenue, profit, and ROI.

2. **Add movie function**
   Users can add new movies using input fields in the sidebar.

3. **ROI calculation**
   The app automatically calculates profit and ROI based on budget and revenue.

4. **Budget vs Revenue bar chart**
   Users can compare each movie’s budget and revenue visually.

5. **Genre distribution pie chart**
   Users can see how movies are distributed by genre.

6. **Decade filter**
   Users can filter movies by decade to focus on a specific time period.

7. **Top ROI ranking**
   The dashboard shows which movies are the most financially successful based on ROI.

### When

This dashboard can be used when preparing film research, comparing movie performance, or exploring examples of successful film production.
It can also be used during presentations to explain how data can support film industry analysis.

### Where

The project will be built as a **Streamlit web app**.
The code will be hosted on **GitHub**, and the project will be introduced through my **GitHub Pages portfolio website**.

### How

The project will be built using:

* Python
* Streamlit
* Pandas
* Plotly
* GitHub
* GitHub Pages
* AI-assisted coding tools such as ChatGPT
