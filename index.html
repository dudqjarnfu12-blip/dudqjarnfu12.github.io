Streamlit Dashboard

🎞️ Film Production Data Hub Dashboard

A Streamlit web app that analyzes movie production data such as title, director, year, genre, budget, revenue, profit, and ROI.

The dashboard includes a budget vs revenue bar chart, genre distribution pie chart, decade filter, ROI calculation, key metric cards, and a sidebar for adding new movies.

This project connects my film major with data visualization by showing how film performance can be explored through interactive charts.
